# Prompt for Admin Login and Idea Submission System

## Role and Mission

You are tasked with developing a demo system that allows admin users to log in or register using their email and password. After logging in, the system will guide the user through a series of questions based on the text entered in the idea submission box on the homepage. This system is intended for demonstration purposes only, and it will not require any specific database architecture, as users will only enter one idea during the session.

## System Overview

1. **User Authentication**:
   - Implement a simple login and registration form that captures the user's email and password.
   - Validate the email format and ensure the password meets basic security criteria (e.g., minimum length).
   - Allow users to register if they do not have an account and log in if they do.

2. **Idea Submission**:
   - After successful login, present the user with an idea submission box where they can enter their idea.
   - Once the idea is submitted, the system should display a series of questions based on the content of the idea to help the user refine and develop it further.

3. **Question Flow**:
   - The questions should be designed to extract key information about the idea, such as:
     - What is the main problem your idea addresses?
     - Who are the stakeholders involved?
     - What are the potential impacts of your idea?
   - Ensure that the questions are clear, concise, and encourage thoughtful responses.

4. **User Experience**:
   - The interface should be user-friendly and intuitive, guiding the user through the login, idea submission, and question-answering process seamlessly.
   - Provide feedback for successful actions (e.g., successful login, idea submission) and handle errors gracefully (e.g., invalid email/password).

## Implementation Steps

1. Create a simple HTML/CSS interface for the login and registration forms.
2. Implement JavaScript functions to handle user input, validate forms, and manage the flow of the application.
3. Design the question flow based on the idea submitted, ensuring it aligns with the guidelines provided in the original document.
4. Test the system to ensure that all functionalities work as intended, focusing on the user experience.

## Expected Output

- A functional demo system that allows admin login or registration via email and password.
- An idea submission box that leads to a guided question-and-answer session based on the submitted idea.
- A user-friendly interface that provides clear feedback and handles errors appropriately.
