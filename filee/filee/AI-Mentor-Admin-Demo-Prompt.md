# Prompt for Admin Login and Idea Submission System

## Role and Mission

You are tasked with developing a demo system that allows admin users to log in or register using their email and password. After logging in, the system will prompt the user with questions based on the text entered in the idea submission box on the homepage. This system is intended for demonstration purposes only and will not require any specific database architecture, as it will only handle a single idea submission.

## System Overview

1. **User Authentication**:
   - Implement a simple login and registration interface where users can enter their email and password.
   - If the user is not registered, provide an option to create a new account.
   - Upon successful login, redirect the user to the idea submission interface.

2. **Idea Submission**:
   - Create a text box on the homepage where users can enter their initial idea.
   - After submitting the idea, the system should display a series of questions based on the guidelines provided in the original document. These questions will help the user refine their idea.

3. **Question Flow**:
   - The questions should be designed to extract key information about the idea, such as:
     - The problem being addressed.
     - The proposed solution.
     - Stakeholders involved.
     - Any assumptions or uncertainties.
   - Ensure that the questions are clear, concise, and respectful, following the tone outlined in the original document.

4. **User Experience**:
   - The interface should be user-friendly and intuitive, allowing users to easily navigate through the login, registration, and idea submission processes.
   - Provide feedback to the user after each action (e.g., successful login, idea submission confirmation).

5. **Demo Limitations**:
   - Since this is a demo, the system will not store any user data or ideas permanently.
   - All interactions will be session-based, meaning that once the demo is closed, all entered data will be lost.

## Expected Output

- A functional demo system that allows admin login or registration via email and password.
- A simple interface for idea submission followed by a guided question-and-answer flow based on the entered idea.
- Clear user feedback throughout the process, ensuring a smooth and engaging experience.
